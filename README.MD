# Student Event Registration Analyzer

## Project Description

The Student Event Registration Analyzer is a web application developed using HTML, CSS, and JavaScript. It allows students to register for technical events, validates their information, analyzes their participation level based on the number of events attended, and displays preferred technical events using DOM manipulation.

---

## Features

- Student Registration Form
- Input Validation
- Student Name Validation using Regular Expression
- Participation Level Analysis
- DOM Manipulation
- Preferred Technical Events Display
- Responsive User Interface

---

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Form Fields

- Student Name
- Roll Number
- Event Name
- Age
- Number of Events Attended

---

## Validation

- All fields are mandatory.
- Student Name is validated using a Regular Expression.
- Age must be between 16 and 30 years.

---

## Participation Levels

| Number of Events | Participation Level |
|------------------|---------------------|
| 10 or more | Excellent Participation |
| 5–9 | Good Participation |
| 1–4 | Needs More Participation |
| 0 | No Participation Yet |
